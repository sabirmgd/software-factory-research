# Evaluate the customer effect

**Status:** planned evaluation; no results collected.

Observe a baseline set of real tasks with appropriate permission. Record task type, difficulty, completion, time, errors, confidence, and the information source used. Avoid collecting more personal or business data than the evaluation needs.

After a limited release, observe comparable tasks and ask users to explain how they determined availability and recognized stale information. Track incorrect commitments and support effort, not only speed or adoption. A faster wrong answer is not improvement.

Separate the effects of training, cleaner data, and interface changes where possible. A small observational comparison can guide the next decision without establishing causal ROI. Report sample size, selection, missing data, and limitations.

Name an outcome owner and a review point. Possible decisions include expand the workflow, fix a data problem, change the interface, narrow its authority, or stop the intervention. Deployment is not the end of the learning loop.
