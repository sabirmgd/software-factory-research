# The request was an AI assistant. The outcome was reliable answers.

**Status:** fictional property-workflow illustration. No named client or real business result is represented.

A customer asks for a chatbot to help staff find available inventory. A code-focused process begins with chat UI, model integration, authentication, and deployment. An outcome-focused process first asks what staff need to accomplish and why the current workflow fails.

Perhaps the problem is unreliable availability data rather than natural-language access. In that case, a conversational interface could make incorrect information easier to consume. The factory should be able to recommend improving the source and a simpler search workflow before adding an assistant.

Read [the discovery and comparison](discovery-and-options.md) and [the outcome-evaluation plan](outcome-evaluation.md). This example illustrates a different endpoint for research: the best next task may not be the originally requested feature.
