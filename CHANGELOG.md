# Changelog

## 0.2.0 — 2026-10-19 — Plain-language revision

Rewrote the main reading experience to make the model easier to understand without weakening its evidence boundaries. Added a five-minute overview, shorter reading routes, one continuous task-assignment story, direct action lists, and compact “do not confuse” distinctions.

Rewrote all thirteen chapters in plainer language. Reduced stacked abstractions, repeated caveats, and long multi-purpose paragraphs. Kept source attribution, permissions, failure paths, uncertainty, and the separation among implementation evidence, release authority, and customer outcomes.

Updated the offline reader order and header so the five-minute explanation appears before the full book. The repository is now hosted privately at `sabirmgd/software-factory-research`; initial-publication instructions are retained only as historical context.

## 0.1.0 — 2026-10-17 — First research edition

Expanded the original implementation blueprint into a 13-chapter research book. Added source-position versus synthesis distinctions, a question-coverage map, the evolution of the model, Make Clear as a first-class understanding capability, three worked examples, optional templates, editable and rendered diagrams, and experiment plans.

Added a narrow runnable assignment model and local publication checks. Their results are not evidence of customer value or a proven software factory. Preserved the earlier blueprint and starter prompt as annotated historical artifacts. Corrected the deprecated HumanLayer repository recommendation and unverified claims about local skill retrieval and interview content.

Remote GitHub publication was not performed in the preparation environment. A guarded GitHub CLI publishing script is provided. Licensing of the original publication remains an author decision; no open-source license is implied.
